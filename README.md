# Sistema de Telemetria e Tomada de Decisão Aeroespacial

## Explicação do Projeto
Este projeto acadêmico consiste em um sistema automatizado em Python para simulação de telemetria, validação de restrições de segurança física, cálculos de autonomia energética e emissão de diagnósticos inteligentes baseados em regras para missões aeroespaciais.

## Instruções de Execução
1. Certifique-se de ter o Python instalado com as bibliotecas necessárias.
2. Abra o arquivo telemetria.ipynb e instale as dependências executando no terminal:
   ```bash
   pip install pandas numpy

3. Execute as células sequencialmente para gerar os dados e visualizar os relatórios
